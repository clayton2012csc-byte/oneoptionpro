# Plano — Painel "Melhores Jogos de Hoje"

## Objetivo
Permitir ao usuário, **agora**, escolher os melhores jogos para apostar hoje usando apenas os
palpites **já salvos** na tabela `auto_tickets` (aba "Bilhetes Automáticos") — **zero chamadas à
API-Football** (cota esgotada + auto-bloqueio em 80%). O usuário aprovou a opção **"Painel
Melhores Jogos de Hoje"**: uma visão única que ranqueia os jogos/palpites por score e
probabilidade, com botão de 1 toque para adicionar ao bilhete (drawer existente).

## Contexto verificado no banco (2026-09-20)
- **Só 5 jogos `pending` com picks nas próximas 24h** em `auto_tickets`:
  Boston Legacy W x Houston Dash W (15:05, NWSL), Lech Poznan x Radomiak (15:15, Ekstraklasa),
  Brinje-Grosuplje x Radomlje (15:15, Eslovênia), Hércules x Juventud Torremolinos (15:30, Espanha
  RFEF), Zaragoza x FC Cartagena (15:30, Espanha RFEF). Nenhum tem `meta.score` no nível do jogo;
  o score existe **por pick**.
- Estrutura de cada pick salvo em `auto_tickets.picks[]`
  (objeto `AutoPick` completo — `auto-ticket.ts:25`):
  `{ market, selection, prob, odd, rule, subType?, status?, evidence?, score?, pillarMin?, elite?,
  pillar?, pillarNotes? }`. Exemplos reais: Lech Poznan → "Mais de 0.5 gol no 1º tempo" (prob 0.71,
  odd 1.40, score 97, elite); Zaragoza → "Resultado 1X2 → Zaragoza" (prob 0.54, odd 1.86, score 92,
  elite).
- `meta` do jogo: `{ lambdaHome, lambdaAway, expectedGoals, expectedCorners, sampleHome, sampleAway,
  headline, flow, goalsSubType, eliteMin, scoreCluster }` (sem score/elite no topo).
- Os picks persistidos são apenas os **emitidos** (`elite !== false`); status `pending` = não
  começou / não conferido. `listAutoTickets` (`auto-tickets.functions.ts:107`) já existe mas o tipo
  `AutoTicketRow.picks` é estreito (sem score/elite) e a query varre 36h — por isso criaremos uma
  função dedicada.

## Decisões assumidas (perguntas deixadas em aberto pelo usuário)
- **Formato do bilhete**: reutilizar o drawer existente (`BetSlipDrawer`), que já agrupa por jogo
  (Aposta Criada com +1 mercado por jogo) e combina odds. Cada pick entra individualmente
  (+1 toque) e o usuário pode combinar jogos num acumulador — mesmo fluxo do MultiplasPanel. Sem
  novo formato de pagamento/fechamento.
- **Escassez**: usar exatamente o que está salvo e avisar claramente (banner/empty state). Sem
  tentar re-varredura (gastaria cota). Se o usuário quiser re-varredura quando a cota voltar, será
  item separado.
- **Ranking**: `topScore` (máximo do score dos 5 Pilares entre os picks) como critério principal;
  desempate por `topProb`. Scores ausentes (picks antigos) caem para ordenação por prob, com nota
  "sem score".

## Riscos
- Poucos dados hoje (5 jogos) → painel honesto com aviso; não bloquear.
- Picks antigos/legados podem ter `score`/`elite` nulos → tratado acima.
- "Placar Exato Seco" é de alta volatilidade → sinalizado e excluído do botão "Montar bilhete".
- Não mexer na lógica do robô/injeção/guard (fora do escopo).
